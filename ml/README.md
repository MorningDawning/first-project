# BeerVia ML — распознавание этикетки

Python-сервис отдельно от `server/` (Node) и `mobile/` (Expo) — здесь живёт CLIP.

## Как это работает

1. **`dataset/`** — фото этикеток по папкам (см. `dataset/README.md` за протоколом съёмки)
2. **`train_clip.py`** — дообучение: CLIP-backbone замороженный, обучается только линейный
   классификатор поверх его эмбеддингов (linear probe — осознанный выбор при небольшом датасете,
   подробности в комментарии наверху скрипта)
3. **`serve.py`** — FastAPI-сервис `/recognize`, принимает фото, возвращает до 3 кандидатов с
   confidence; пока чекпоинта нет — честно отвечает «не распознано»
4. Бэкенд (`server/src/routes/scan.ts`) вызывает `/recognize`, и если распознавание уверенное —
   ищет пиво по названию в своей базе; если нет (или сервис выключен) — уходит в резервный сценарий
5. Те же фото, что собираются здесь для обучения, становятся и фото пива в самом приложении — см.
   «Реальные фото в приложении» ниже

## Реальные фото в приложении

В карточке пива и в списках приложение раньше показывало угаданные внешние ссылки (иногда неверные —
вместо фото просто отображалась заглушка). Теперь бэкенд отдаёт фото прямо из `dataset/` статикой:

```bash
cd server
npm run sync-photos
```

Скрипт берёт первое фото (по алфавиту) из каждой папки `dataset/<марка>/`, у которой есть фото, и
записывает его в базу как `imageUrl` этой марки. Можно запускать повторно в любой момент по мере
пополнения датасета — ничего не ломает. Пивам без фото в датасете приложение показывает generated-
заглушку (цвет + эмодзи), а не угаданную ссылку.

## Установка

```bash
cd ml
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Обучение

1. Наберите фото по `dataset/README.md` (минимум 30 на марку — можно смешивать студийные фото из
   интернет-магазинов с настоящими фото телефоном, там же объяснено, зачем нужны оба вида)
2. Запустите:
   ```bash
   python train_clip.py --data dataset --out checkpoint.joblib
   ```
   Скрипт выведет точность на кросс-валидации — по ней сразу видно, хватает ли данных. Каждое фото
   автоматически размножается 5 аугментированными копиями (поворот/яркость/размытие/обрезка) —
   отключить или изменить: `--augment-count 0` (или другое число).

## Запуск сервиса

```bash
BEERVIA_ML_CHECKPOINT=checkpoint.joblib uvicorn serve:app --host 0.0.0.0 --port 8001
```

Проверить: `curl http://localhost:8001/health` → `{"ok":true,"modelLoaded":true}`.

Бэкенду (`server/.env`) нужно указать, где искать сервис:
```
ML_SERVICE_URL="http://localhost:8001"
```

Если `ML_SERVICE_URL` не задан или сервис недоступен — бэкенд просто использует резервный сценарий,
всё остальное приложение продолжает работать как обычно.

## Стоимость запуска в проде

CLIP ViT-B/32 достаточно лёгкий, чтобы инференс работал даже на CPU (доли секунды на фото) — отдельный
GPU для старта не обязателен, только для обучения на больших датасетах ускорит дело.
