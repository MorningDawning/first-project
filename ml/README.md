# BeerVia ML: распознавание этикетки по фото

Отдельный Python-сервис рядом с `server/` (Node) и `mobile/` (Expo).

## Как это работает

1. Нейросеть **CLIP** превращает любое фото в набор чисел (вектор): похожие картинки дают близкие векторы.
2. **Галерея** — векторы эталонных фото каждого пива из папки `dataset/`.
3. Пользователь фотографирует банку. Сервис сравнивает её вектор с галереей:
   - очень похоже на какое-то пиво и заметно лучше остальных → «узнали»;
   - есть сомнения → приложение показывает «Возможно, это…» с вариантами;
   - непохоже ни на что → честно «не узнали», приложение предлагает штрихкод или добавить пиво.

Почему галерея, а не «обучение классификатора». В каталоге будут сотни сортов, и он растёт: классификатор
пришлось бы переобучать при каждой новой марке и он всегда выбирает «одну из известных», даже для
незнакомой банки. С галереей новое пиво = несколько фото и запуск `build_gallery.py` (секунды), а
незнакомая этикетка не выдаётся за чужую.

Файлы:

| Файл | Зачем |
|---|---|
| `fetch_off_photos.py` | скачать фото упаковок из открытой базы Open Food Facts в `dataset/` |
| `build_gallery.py` | собрать галерею (`gallery.npz` и `gallery.json`), подобрать порог «узнали» |
| `evaluate.py` | проверить качество на фото, которых в галерее нет |
| `serve.py` | сервис `/recognize`, к нему обращается `server/` |

## Установка (Windows)

1. Установите Python 3.11 или новее с python.org. На первом экране установщика поставьте галочку
   **Add python.exe to PATH**. Проверка: `python --version`.
2. В Git Bash:
   ```
   cd /d/beervia-app/ml
   python -m venv venv
   source venv/Scripts/activate
   pip install -r requirements.txt
   ```
   Скачивается PyTorch, это несколько сотен мегабайт, ждать 5–10 минут. Признак активной среды:
   в начале строки `(venv)`. Каждый раз в новом окне сначала `source venv/Scripts/activate`.

## Шаг 1. Собрать фото

```
python fetch_off_photos.py
```

Скрипт ищет каждую марку из `dataset/labels.json` в Open Food Facts и кладёт фото упаковки в
`dataset/<марка>/`. Это идёт неторопливо (сервис просит не больше 10 запросов в минуту), 18 марок
займут пару минут. В конце покажет, для каких марок фото не нашлось.

**Это фото упаковок «как в магазине». Настоящие снимки телефоном нужны обязательно:** добавьте по
5–10 своих фото каждой марки в её папку (разные ракурсы, свет, фон, см. `dataset/README.md`). Иначе
на реальных снимках качество будет заметно ниже. Отсутствующие марки тоже снимайте сами.

## Шаг 2. Собрать галерею и проверить качество

```
python build_gallery.py
python evaluate.py
```

Первый запуск скачивает веса CLIP (около 350 МБ), для этого может понадобиться VPN.

`evaluate.py` показывает три числа:
- **Верное пиво первым**: как часто узнаёт новое фото знакомой марки. Хорошо: 85% и выше.
- **Из них верно**: если приложение уверенно ответило, то как часто правильно. Хорошо: 95% и выше.
- **«Не знаю» для чужого**: насколько честно отвергает незнакомую банку. Хорошо: 85% и выше.

Ниже отчёт по маркам и что с чем путает. Если результат плохой, чаще всего не хватает разнообразных
фото: добавьте снимки телефоном в проблемные папки и запустите оба скрипта снова.

## Шаг 3. Запустить сервис

```
uvicorn serve:app --host 0.0.0.0 --port 8001
```

Проверка: `http://localhost:8001/health` должен показать `"modelLoaded": true`.

В `server/.env` укажите (и перезапустите сервер):
```
ML_SERVICE_URL="http://localhost:8001"
```

Дальше в приложении фото этикетки сначала сверяется с галереей.

## Как добавить новое пиво

1. Добавьте строку в `dataset/labels.json`: `"папка": {"beer": "Название как в каталоге", "brewery": "Пивоварня как в каталоге"}`.
2. Положите фото в `dataset/папка/` (или `python fetch_off_photos.py --only папка`).
3. `python build_gallery.py`, затем перезапустите `serve.py`.

## Настройки

- Порог «узнали» подбирается автоматически при сборке галереи и записывается в `gallery.json`.
  Свой порог: переменная `BEERVIA_ML_THRESHOLD` (например `0.85`) при запуске `serve.py`.
- Меньше ложных «узнал»: поднимите порог. Чаще предлагает варианты: опустите.

## Сколько это стоит на сервере

CLIP ViT-B/32 работает и на обычном процессоре: доли секунды на фото, нужно около 1–2 ГБ памяти.
Отдельная видеокарта не требуется.

## Проверка кода без нейросети

`pytest tests` прогоняет весь конвейер на искусственных «этикетках» со встроенным упрощённым
эмбеддером (без скачивания моделей). Это проверка логики, а не качества на настоящих банках.
