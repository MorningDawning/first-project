# Датасет для распознавания этикеток

Одна папка — одна марка пива (18 штук, ровно те, что уже есть в базе `server/prisma/seed.ts`).
Соответствие «папка → точное название в базе» зафиксировано в `labels.json` — не переименовывайте
папки без обновления этого файла.

## Сколько снимать

**Минимум 30 фото на марку, лучше 50.** Меньше 15-20 — классификатор не наберёт достаточно сигнала.
(Скрипт обучения сам размножает каждое фото аугментациями — см. ниже, так что 15-20 *разных*
исходных фото на марку уже дают приемлемый старт.)

## Можно ли брать фото из интернет-магазинов

Да, это законный способ быстро набрать объём — но с оговоркой. Фото товаров в магазинах —
студийные: идеальный свет, чистый фон, этикетка строго анфас. Реальные фото пользователей телефоном
— наоборот, «грязные»: углы, блики, мятые банки, случайный фон. Если обучить только на студийных
фото, модель может не узнавать реальные снимки пользователей.

**Как использовать правильно:**
- Берите фото вручную (сохраняете со страницы товара как обычно) — не пишите скрипт-скрапер,
  автоматический сбор с чужого магазина спорнее с точки зрения условий использования сайта, а
  вручную сохранить то, что и так видно в браузере — нормально.
- Добавьте к ним **хотя бы 5-10 настоящих фото телефоном** на каждую марку (в разных условиях, как
  описано в протоколе ниже) — этого достаточно, чтобы модель не «удивлялась» реальным фото.
- Скрипт обучения (`train_clip.py`) автоматически аугментирует каждое исходное фото (поворот,
  яркость, размытие, обрезка) — это частично компенсирует нехватку разнообразия в студийных снимках.

Итого: студийные фото из магазинов — для объёма и охвата марок, немного реальных фото телефоном —
для честности модели по отношению к тому, как её реально будут использовать.

## Протокол съёмки (важно соблюдать разнообразие, а не количество ради количества)

Для каждой марки постарайтесь набрать фото по всем осям ниже — иначе модель выучит не «как выглядит
Punk IPA», а «как выглядит стол на кухне», и не будет работать на других фонах.

- **Ракурс:** анфас, поворот на ~30° влево/вправо, немного сверху, немного снизу — 5-6 ракурсов на банку
- **Освещение:** дневной свет у окна, жёлтый комнатный свет, вспышка телефона в темноте
- **Состояние банки:** новая ровная, слегка помятая, с каплями конденсата (реалистичные условия — люди
  не сканируют идеально сухие банки из магазина)
- **Фон:** в руке, на столе, в холодильнике, на фоне бара/полки

## Технические требования

- Реальные фото (не из магазина) снимайте на тот же телефон, на котором будет использоваться
  BeerVia — модель должна видеть хотя бы часть «настоящих» пользовательских снимков
- Формат `.jpg` или `.png`, без ограничений по разрешению — препроцессинг CLIP сам приведёт к 224×224
- Именование файлов внутри папки произвольное (`001.jpg`, `IMG_0231.jpg` — не важно)

## Структура

```
dataset/
  labels.json          ← папка → точное название пива в БД
  punk-ipa/
    001.jpg
    002.jpg
    ...
  hazy-jane/
    ...
```

Папки уже созданы под все 18 марок — просто кладите туда фото. Марки без фото скрипт обучения
пропустит с предупреждением (распознавание для них тогда продолжит уходить в резервный сценарий на
бэкенде — см. `server/src/routes/scan.ts`).

## Важно: «Северный ветер» — вымышленная пивоварня

Три марки (`imperial-stout`, `medovyy-el`, `baltiyskiy-porter`) принадлежат пивоварне «Северный
ветер», которую я придумал для демо-данных — её не существует в реальности, и фото её банок нигде
в интернет-магазине не найти. Для этих трёх марок нужны только настоящие фото (можно взять похожую
по стилю банку любого craft-пива и переклеить/представить как эту марку для теста — либо, если
хотите честности, заменить их на реальные российские крафтовые пивоварни в `server/prisma/seed.ts`
до сбора датасета).
