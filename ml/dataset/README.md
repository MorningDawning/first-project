# Датасет для распознавания этикеток

Одна папка — одна марка пива (18 штук, ровно те, что уже есть в базе `server/prisma/seed.ts`).
Соответствие «папка → точное название в базе» зафиксировано в `labels.json` — не переименовывайте
папки без обновления этого файла.

## Сколько снимать

**Минимум 30 фото на марку, лучше 50.** Меньше 15-20 — классификатор не наберёт достаточно сигнала.

## Протокол съёмки (важно соблюдать разнообразие, а не количество ради количества)

Для каждой марки постарайтесь набрать фото по всем осям ниже — иначе модель выучит не «как выглядит
Punk IPA», а «как выглядит стол на кухне», и не будет работать на других фонах.

- **Ракурс:** анфас, поворот на ~30° влево/вправо, немного сверху, немного снизу — 5-6 ракурсов на банку
- **Освещение:** дневной свет у окна, жёлтый комнатный свет, вспышка телефона в темноте
- **Состояние банки:** новая ровная, слегка помятая, с каплями конденсата (реалистичные условия — люди
  не сканируют идеально сухие банки из магазина)
- **Фон:** в руке, на столе, в холодильнике, на фоне бара/полки

## Технические требования

- Снимайте на тот же телефон (и по возможности то же приложение-камеру / формат), на котором будет
  использоваться BeerVia — не сканы из интернета и не студийные фото пивоварен, модель должна
  учиться на «настоящих» пользовательских снимках
- Формат `.jpg` или `.png`, без ограничений по разрешению — препроцессинг CLIP сам приведёт к 224×224
- Именование файлов внутри папки произвольное (`001.jpg`, `IMG_0231.jpg` — не важно)

## Структура

```
dataset/
  labels.json          ← папка → точное название пива в БД
  punk-ipa/
    001.jpg
    002.jpg
    ...
  hazy-jane/
    ...
```

Папки уже созданы под все 18 марок — просто кладите туда фото. Марки без фото скрипт обучения
пропустит с предупреждением (распознавание для них тогда продолжит уходить в резервный сценарий на
бэкенде — см. `server/src/routes/scan.ts`).
